## Task 2 节点升级的超时处理

基线 `243ca27`。发布 PR 在 GitHub 的 Ubuntu 26.04.1 runner 两次失败。
同一版本的官方容器复现。最小 A/B 复现中 uutils timeout 返回 124 后子进程仍存活，
GNU timeout 返回 137 后子进程已退出。

| 契约 | 成功 | 失败 | 取消/超时和清理 | 验证 |
|---|---|---|---|---|
| 支持 Ubuntu 26.04 的节点升级并维持原有超时语义 | 使用 GNU timeout 验证候选，保留各系统上正常升级 | 检查失败或缺 GNU 实现时中止，原版本仍可用 | 沿用独立进程组、信号处理与锁生命周期；超时不得留下子进程 | 在 26.04 与 24.04 运行原升级测试，观察超时、信号、锁和文件回滚断言 |

范围为 bootstrap 超时命令选择、升级文档和三个已有断言的命令观察。
测试验证进程由 GNU timeout 执行，并保留 fd、超时、子进程退出与锁的断言。
