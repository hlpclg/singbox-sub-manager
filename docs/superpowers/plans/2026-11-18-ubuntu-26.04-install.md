# Ubuntu 26.04 安装支持

基线 `86ea9f9`。随 v0.10.0 发布。范围为订阅中心安装/更新/回滚、节点 bootstrap
及 Reality 服务的 OS 支持检查、相关测试、发布镜像与用户文档。

| 契约 | 成功 | 失败 | 取消/超时、持久化 | 验证 |
|---|---|---|---|---|
| Ubuntu 26.04.1 LTS 使用 OS ID ubuntu 与 VERSION_ID 26.04；保留原支持范围 | 三个入口接受，原支持版本仍通过 | 非支持版本在预检拒绝；bootstrap 不下载 | OS 判断无新增阻塞或持久化；沿用既有预检与清理 | bootstrap OS 矩阵、Go 平台单测、Ubuntu 26.04 镜像中的订阅中心预检 |
| Ubuntu 26.04 加入发布 smoke | APT 依赖与 Caddy 在该镜像可安装 | 任一矩阵单元失败则阻止发布 | 沿用容器与 Actions 生命周期 | 本地执行 Ubuntu 26.04 smoke，发布时等待矩阵与资产构建；容器不覆盖 systemd |

提交范围为本计划、上述生产入口、测试及发布和安装文档。专项门禁覆盖 OS 检查和
Ubuntu 26.04 APT smoke。完整门禁包括 CI Shell 套件、ShellCheck，以及 Go 1.22
容器中的测试、race、vet 和 gofmt 检查。发布沿用 v0.10.0 标签触发及资产核对。
