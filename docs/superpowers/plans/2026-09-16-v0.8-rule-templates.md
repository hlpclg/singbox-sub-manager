# v0.8 规则模板与策略组 — 实施计划

> **Goal:** 把 `clash.yaml` 改为内置 14 组策略组模板，收紧 `proxyctl validate` 的结构校验，并交付准确的升级与订阅重新生成说明。
>
> **Architecture:** `internal/render` 以内部数据描述策略组、rule-providers 与规则，渲染确定、可复现；保留名冲突检查在任何文件系统操作前执行；`validate` 的 YAML 结构层只依据输入 YAML 的实际定义。Shell 兜底保留旧模板并明确告警。
>
> **Tech Stack:** Go 1.22、`gopkg.in/yaml.v3`（已在 `go.mod`）、Bash。
>
> **Spec:** `docs/superpowers/specs/2026-09-16-v0.8-rule-templates-design.md`（2026-09-16 第二轮修订后设计复审通过）。下文「设计 §x」均指该文档章节。

> **For agentic workers:** 每个 Task 遵循 `docs/agent-workflows/task-lifecycle.md` 的执行顺序：契约确认 → 验收矩阵 → 最小实施 → 聚焦测试 → 规格符合性审查 → 代码质量审查 → Task 专项门禁 → 计划与用户文档更新 → 主提交 → 状态封账提交 → 下一 Task。

**依据设计**：设计文档第 1–9 节。按根 `AGENTS.md`，本计划只描述契约、输入输出、不变量、验收测试、验证命令和提交范围，不提供生产实现代码，不规定非必要的内部 helper；下文精确定义的导出符号与 `validateClashYAML` 属于测试契约。

## 风险与编排

- 业务风险：中央 L1（设计 §8）。普通功能，不涉及认证、密钥、信任边界或服务端外部请求。每个 Task 由未参与实施的审查者独立终审，审查与复审按 `docs/agent-workflows/review-closure.md`。
- 流程复杂度：中等，2 个 Task 顺序依赖；Task 2 不改 Go 代码，依赖 Task 1 已封账。
- 并发与 I/O：不适用取消、超时与并发测试（设计 §7.4）。渲染为纯函数；`Write`、`merge`、`validate` 的文件 I/O 为本地同步调用，无 context、goroutine、channel、锁或网络调用。验收矩阵中相应列统一记为「不适用（设计 §7.4）」。

**Stage:** 实施。**依赖：** 设计已批准。

- Modify 或 Create：`cmd/proxyctl/main_test.go` 或同包新测试文件

**接口契约**

- `func Clash(ns []nodes.Node) string`：签名不变；仍渲染传入的全部节点（调用方负责按 `Enabled` 过滤，与 v0.7.1 相同）。
- `func Shadowrocket(ns []nodes.Node) string`：不变。
- 新增 `func ReservedNames() []string`：每次返回新切片，内容与顺序为设计 §3.2 表中 14 个组名按 1–14 顺序，后接 `DIRECT`、`REJECT`，共 16 项。修改返回值不影响后续调用。
- 新增 `func CheckNodeNames(ns []nodes.Node) error`：忽略 `Enabled=false` 的节点；按输入顺序遇到第一个名称与保留名完全相等的启用节点时返回非 nil 错误，错误文本包含该节点名；否则返回 nil。
- `func Write(output string, ns []nodes.Node) error`：签名不变；先调用 `CheckNodeNames`，出错时直接返回该错误，此前不调用任何文件系统操作（包括 `MkdirAll`）。
- `cmd/proxyctl` 包内新增 `func validateClashYAML(doc string) error`（测试契约）：实现设计 §5 结构层 1–6，失败返回描述性错误，通过返回 nil。不读取渲染器数据。
- `cmdValidate`：节点层保留现有检查，在其后调用 `render.CheckNodeNames`；随后以 `render.Clash` 输出调用 `validateClashYAML`；失败时 stderr 以 `validation failed: ` 开头并返回 1；`sr.txt` 校验与成功输出不变。删除预置的 `自动选择`、`节点选择` 成员集合。
- 规则目标解析：`MATCH` 规则取第 2 个逗号分段，其他规则取第 3 个；分段数不足（`MATCH` 少于 2 段、其他少于 3 段）视为失败。
