## Required contracts

### UDP 443

- Stable ID: `port.udp443`; stable name: `UDP 443`.
- Inspect injected `/proc/net/udp`-format files. Production defaults are `/proc/net/udp` and `/proc/net/udp6`.
- Parse the local-address column, not remote address or arbitrary line substrings.
- Match local port 443 by numeric/hex meaning; accept normal uppercase/lowercase hex representation without matching malformed or partial values.
- IPv4 or IPv6 presence is sufficient. This check reports only that a local UDP socket uses port 443; it must not claim Hysteria2 or remote-node health.
- PASS message: `listening`. No matching listener: FAIL with `not listening`.
- If no configured/default proc source can be read: FAIL with a stable non-sensitive diagnostic. A missing first source must not prevent checking a readable second source.
- Check context before starting and between multiple source reads. Go stdlib local file reads are not cancellable; document this bounded pseudo-file exception and do not add a timeout goroutine.

### TCP 443 and TCP 80

- Stable IDs/names: `port.tcp443` / `TCP 443`, `port.tcp80` / `TCP 80`.
- Default targets: `127.0.0.1:443` and `127.0.0.1:80`; tests inject ephemeral addresses.
- Use a context-aware TCP dial bounded by `cfg.Timeouts.TCPConnect` and the parent context.
- PASS only after a connection is established; message `reachable`.
- Refusal, dial error, cancellation, or timeout is FAIL with a stable non-sensitive message.
- Close every successful connection before returning.
- To test timeout deterministically, add the smallest context-aware dial seam needed by the package. It may live on `Config` or the internal TCP check, but it must default to production `net.Dialer` behavior and must not prescribe or expose an unnecessary public helper.
- Do not use public IPs, unroutable “black-hole” addresses, fixed ports, or sleep-only timing assumptions to simulate timeout.

## Required tests

Write tests before production implementation. Each test must be deterministic and offline.

### UDP parser/check matrix

- IPv4 proc row containing local `01BB` passes.
- IPv6 proc row passes when the IPv4 source is missing or has no match.
- A remote-address `01BB` with a different local port does not pass.
- Ports such as `101BB`, `01B`, malformed rows, headers, and blank lines do not pass.
- Readable files with no 443 return `not listening`.
- All sources missing/unreadable return the stable read failure.
- Pre-cancelled context returns promptly without starting further reads.
- Assert exact check ID, name, status, and message.

### TCP check matrix

- TCP 443 succeeds against an ephemeral `127.0.0.1:0` listener.
- TCP 80 uses its own configured address rather than the TCP 443 address.
- A closed ephemeral address fails.
- A context-aware fake dial blocks until `ctx.Done()`; with a short TCP timeout, assert prompt return, FAIL status, and proof that the fake observed cancellation.
- A pre-cancelled parent context does not perform a real dial.
- A successful fake connection records that `Close` was called.
- Assert exact IDs, names, statuses, messages, and production default address selection.

### Regression constraints

- No goroutine-count assertions based on `runtime.NumGoroutine`; use explicit channels/counters owned by the fake.
- No test may access host `/proc`, real port 80/443, systemd, public DNS, or public network.
- Tests must pass with `-race` and repeated focused execution.
