# v0.4 Health Check (local) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `proxyctl health` — a read-only, report-only health check of the subscription-center host (services, ports, configs, subscription files, HTTPS/TLS, DNS, disk), with text and JSON output.

**Architecture:** A new `internal/health` package defines a `Check` interface and 15 checks, each isolated behind injectable seams (a `CommandRunner` for `systemctl`/`sing-box`/`caddy`, function fields for DNS/disk, address+CA fields for TCP/TLS) so every unit test runs without touching real systemd, the network, or the filesystem beyond `t.TempDir()`. A runner executes local checks serially and network checks concurrently (max 4) under a 30 s overall cap. A `cmd/proxyctl` `health` subcommand resolves config (flag → `install.json` → Caddyfile), runs the checks, renders, and maps the aggregate status to an exit code.

**Tech Stack:** Go 1.22 stdlib only (`context`, `net`, `crypto/tls`, `crypto/x509`, `net/http`, `encoding/json`, `syscall`, `text/tabwriter`, `os/exec`). No new dependencies.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from `docs/superpowers/specs/2026-08-01-v0.4-health-check-design.md`.

- **Module path:** `github.com/hlpclg/singbox-sub-manager`. Go 1.22.
- **`go` is NOT on PATH.** Run every Go command inside Docker:
  `docker run --rm -v "$PWD":/w -w /w golang:1.22 go test ./...`
  (substitute `go vet ./...`, `gofmt -l .`, `go build ./...`, `go mod tidy` as needed).
- **Read-only, report-only.** No check may modify system state. No auto-repair, no auto-disable, no service restart.
- **No new dependencies.** Stdlib only. Do not edit `go.mod`/`go.sum`.
- **Status values (exact):** `pass`, `warn`, `fail` (lowercase, as JSON string).
- **Aggregate → exit code:** any `fail` → `unhealthy`/exit 1; no fail but any `warn` → `degraded`/exit 2; all pass → `healthy`/exit 0; CLI arg/internal error → exit 3.
- **Pinned timeouts (upper bounds, never expected latency):** TCP connect 2s, DNS 3s, TLS 5s, HTTP 8s, command exec 10s, overall 30s. A check unfinished when the 30s overall cap fires is recorded `fail` with message `timeout`.
- **Concurrency:** local file/config checks serial; DNS/HTTPS/TLS concurrent; max concurrency 4; every check uses its own `context.WithTimeout`; no un-timed network calls; all goroutines must be able to exit.
- **Sensitive-data rule:** never write password, OBFS password, subscription token, or the full subscription URL into any output or log.
- **Stable JSON schema.** Field names and check `id`s are a contract (see Task 9). Do not rename.
- **Stable check `id`s:** `service.singbox`, `service.caddy`, `port.udp443`, `port.tcp443`, `port.tcp80`, `config.singbox`, `config.caddy`, `subscription.token`, `subscription.clash`, `subscription.sr`, `http.subscription`, `tls.certificate`, `tls.expiry`, `dns.resolve`, `disk.space`.
- **Verified real paths (do not invent others):**
  - sing-box config: `/etc/sing-box/config.json`
  - caddy config: `/etc/caddy/Caddyfile` (validate with `--adapter caddyfile`)
  - subscription root: `/var/www/proxy-sub`; files at `/var/www/proxy-sub/<token>/clash.yaml` and `.../sr.txt`
  - token file: `/var/lib/singbox-sub-manager/token` (legacy fallback `/etc/proxy-sub-token`)
  - subscription URL: `https://<domain>/<token>/clash.yaml` (and `.../sr.txt`)
  - install state: `/etc/singbox-sub-manager/install.json`
- **Token regex:** `^[A-Za-z0-9_-]{16,128}$`.
- **HTTPS/TLS use a loopback dial:** dial `127.0.0.1:443`, present SNI/Host = domain (avoids hairpin-NAT false FAILs), verify cert against domain.
- **CommandRunner judges `systemctl is-active` by the `active` output**, not exit code or localized text.
- **Config-check tool-missing → WARN; present-but-invalid → FAIL.**

```go
package health

import (
	"context"
	"crypto/x509"
	"time"
)

// Status is a single check's outcome.
type Status string

const (
	StatusPass Status = "pass"
	StatusWarn Status = "warn"
	StatusFail Status = "fail"
)

// Timeouts holds the pinned per-operation upper bounds. Never treat these as
// expected latencies; they are ceilings.
type Timeouts struct {
	TCPConnect time.Duration
	DNS        time.Duration
	TLS        time.Duration
	HTTP       time.Duration
	Command    time.Duration
	Overall    time.Duration
}

// DefaultTimeouts returns the values pinned by the spec.
func DefaultTimeouts() Timeouts {
	return Timeouts{
		TCPConnect: 2 * time.Second,
		DNS:        3 * time.Second,
		TLS:        5 * time.Second,
		HTTP:       8 * time.Second,
		Command:    10 * time.Second,
		Overall:    30 * time.Second,
	}
}

// CommandResult is the outcome of running an external command.
type CommandResult struct {
	Stdout   string
	Stderr   string
	ExitCode int
	NotFound bool  // binary not found in PATH
	Err      error // execution error other than a non-zero exit
}

// CommandRunner runs external commands. Production uses ExecRunner; tests
// inject a fake.
type CommandRunner interface {
	Run(ctx context.Context, name string, args ...string) CommandResult
}

// Config carries everything the checks need. Zero-valued injectable seams
// (Runner, LookupHost, DiskFree, RootCAs) fall back to production behavior;
// tests set them to keep checks off the real system.
type Config struct {
	Domain           string
	SingboxConfig    string // /etc/sing-box/config.json
	CaddyConfig      string // /etc/caddy/Caddyfile
	SubscriptionRoot string // /var/www/proxy-sub
	TokenFile        string // /var/lib/singbox-sub-manager/token

	// Token is resolved once by ResolveConfig. Empty means unavailable; the
	// reason is in TokenErr. Checks that need the token cascade to FAIL when
	// it is empty.
	Token    string
	TokenErr error

	// Local probe seams. Empty strings mean use the production defaults.
	ProcNetUDP      []string // default {/proc/net/udp, /proc/net/udp6}
	TCP443Addr      string   // default 127.0.0.1:443
	TCP80Addr       string   // default 127.0.0.1:80
	LoopbackTLSAddr string   // default 127.0.0.1:443 (HTTPS + TLS dial target)
	RootCAs         *x509.CertPool // nil = system roots

	// Injectable seams (nil = production implementation).
	Runner     CommandRunner
	LookupHost func(ctx context.Context, host string) ([]string, error)
	DiskFree   func(path string) (uint64, error)

	Timeouts Timeouts
}

// Check is one health probe.
type Check interface {
	ID() string
	Name() string
	Run(ctx context.Context, cfg Config) Result
}
```

```go
package health

// Result is one check's report.
type Result struct {
	ID         string `json:"id"`
	Name       string `json:"name"`
	Status     Status `json:"status"`
	Message    string `json:"message"`
	DurationMS int64  `json:"duration_ms"`
}

// Overall is the aggregate verdict.
type Overall string

const (
	Healthy   Overall = "healthy"
	Degraded  Overall = "degraded"
	Unhealthy Overall = "unhealthy"
)

// Aggregate reduces per-check statuses: any fail dominates, else any warn, else healthy.
func Aggregate(results []Result) Overall {
	hasFail, hasWarn := false, false
	for _, r := range results {
		switch r.Status {
		case StatusFail:
			hasFail = true
		case StatusWarn:
			hasWarn = true
		}
	}
	switch {
	case hasFail:
		return Unhealthy
	case hasWarn:
		return Degraded
	default:
		return Healthy
	}
}

// ExitCode maps an Overall to the process exit code. Exit 3 (arg/internal
// error) is decided by the CLI, not here.
func ExitCode(o Overall) int {
	switch o {
	case Unhealthy:
		return 1
	case Degraded:
		return 2
	default:
		return 0
	}
}

// Summary counts checks by status.
type Summary struct {
	Passed   int `json:"passed"`
	Warnings int `json:"warnings"`
	Failed   int `json:"failed"`
}

// Summarize tallies results into a Summary.
func Summarize(results []Result) Summary {
	var s Summary
	for _, r := range results {
		switch r.Status {
		case StatusPass:
			s.Passed++
		case StatusWarn:
			s.Warnings++
		case StatusFail:
			s.Failed++
		}
	}
	return s
}
```

### Task 2: Runner (serial + concurrent, overall cap, timeout→FAIL)

**Files:**
- Create: `internal/health/runner.go`
- Test: `internal/health/runner_test.go`

**Interfaces:**
- Consumes: `Check`, `Config`, `Result`, `StatusFail`, `Timeouts` (Task 1).
- Produces: `func RunAll(ctx context.Context, cfg Config, checks []Check, concurrentIDs map[string]bool) []Result`.
  - Runs `checks` whose ID is in `concurrentIDs` in background goroutines with max concurrency 4; the rest serially in slice order.
  - Returns results in the **same order as `checks`** (deterministic, for stable output).
  - Wraps the whole run in `context.WithTimeout(ctx, cfg.Timeouts.Overall)`; any check that has not returned when that deadline fires is recorded `StatusFail` with `Message:"timeout"`.
  - Sets each result's `DurationMS`.

- [ ] **Step 1: Write `internal/health/runner.go`**

```go
package health

import (
	"context"
	"sync"
	"time"
)

const maxConcurrency = 4

// RunAll executes checks. Checks whose ID is in concurrentIDs run in parallel
// (bounded to maxConcurrency); all others run serially in order. Results are
// returned in the same order as checks. The whole run is bounded by
// cfg.Timeouts.Overall; a check still running when that fires is reported as a
// timeout failure.
func RunAll(ctx context.Context, cfg Config, checks []Check, concurrentIDs map[string]bool) []Result {
	overall := cfg.Timeouts.Overall
	if overall <= 0 {
		overall = DefaultTimeouts().Overall
	}
	ctx, cancel := context.WithTimeout(ctx, overall)
	defer cancel()

	results := make([]Result, len(checks))

	var wg sync.WaitGroup
	sem := make(chan struct{}, maxConcurrency)
	for i, c := range checks {
		if !concurrentIDs[c.ID()] {
			continue
		}
		wg.Add(1)
		go func(i int, c Check) {
			defer wg.Done()
			sem <- struct{}{}
			defer func() { <-sem }()
			results[i] = runOne(ctx, cfg, c)
		}(i, c)
	}

	// Serial checks run inline, in order, while the concurrent ones proceed.
	for i, c := range checks {
		if concurrentIDs[c.ID()] {
			continue
		}
		results[i] = runOne(ctx, cfg, c)
	}

	wg.Wait()
	return results
}

// runOne runs a single check, enforcing the overall context deadline even if
// the check itself ignores ctx. The done channel is buffered so the inner
// goroutine never blocks and cannot leak: it always completes and sends once
// each check's own per-op timeout (derived from ctx) fires.
func runOne(ctx context.Context, cfg Config, c Check) Result {
	start := time.Now()
	done := make(chan Result, 1)
	go func() { done <- c.Run(ctx, cfg) }()
	select {
	case res := <-done:
		res.ID, res.Name = c.ID(), c.Name()
		res.DurationMS = time.Since(start).Milliseconds()
		return res
	case <-ctx.Done():
		return Result{
			ID:         c.ID(),
			Name:       c.Name(),
			Status:     StatusFail,
			Message:    "timeout",
			DurationMS: time.Since(start).Milliseconds(),
		}
	}
}
```

package health

import (
	"context"
	"sync/atomic"
	"testing"
	"time"
)

// fakeCheck is a controllable Check for runner tests.
type fakeCheck struct {
	id     string
	status Status
	delay  time.Duration
	active *int32 // optional: tracks concurrent in-flight count
	peak   *int32
}

func (f fakeCheck) ID() string   { return f.id }
func (f fakeCheck) Name() string { return f.id }
func (f fakeCheck) Run(ctx context.Context, cfg Config) Result {
	if f.active != nil {
		n := atomic.AddInt32(f.active, 1)
		for {
			p := atomic.LoadInt32(f.peak)
			if n <= p || atomic.CompareAndSwapInt32(f.peak, p, n) {
				break
			}
		}
		defer atomic.AddInt32(f.active, -1)
	}
	if f.delay > 0 {
		select {
		case <-time.After(f.delay):
		case <-ctx.Done():
			return Result{Status: StatusFail, Message: "ctx"}
		}
	}
	return Result{Status: f.status}
}

func TestRunAllPreservesOrder(t *testing.T) {
	checks := []Check{
		fakeCheck{id: "a", status: StatusPass},
		fakeCheck{id: "b", status: StatusWarn},
		fakeCheck{id: "c", status: StatusFail},
	}
	cfg := Config{Timeouts: DefaultTimeouts()}
	got := RunAll(context.Background(), cfg, checks, map[string]bool{"b": true, "c": true})
	if got[0].ID != "a" || got[1].ID != "b" || got[2].ID != "c" {
		t.Fatalf("order not preserved: %+v", got)
	}
	if got[0].Status != StatusPass || got[1].Status != StatusWarn || got[2].Status != StatusFail {
		t.Fatalf("statuses wrong: %+v", got)
	}
}

func TestRunAllConcurrencyCap(t *testing.T) {
	var active, peak int32
	var checks []Check
	ids := map[string]bool{}
	for i := 0; i < 10; i++ {
		id := string(rune('a' + i))
		checks = append(checks, fakeCheck{id: id, status: StatusPass, delay: 20 * time.Millisecond, active: &active, peak: &peak})
		ids[id] = true

	cfg := Config{Timeouts: DefaultTimeouts()}
	RunAll(context.Background(), cfg, checks, ids)
	if peak > maxConcurrency {
		t.Fatalf("peak concurrency %d exceeded cap %d", peak, maxConcurrency)
	}
}

	checks := []Check{fakeCheck{id: "slow", status: StatusPass, delay: time.Second}}
	cfg := Config{Timeouts: DefaultTimeouts()}

	if got[0].Status != StatusFail || got[0].Message != "timeout" {
		t.Fatalf("expected timeout fail, got %+v", got[0])
	}
}

package health

import (
	"bytes"
	"context"
	"errors"
	"os/exec"
)

// ExecRunner is the production CommandRunner.
type ExecRunner struct{}

// Run executes name with args, capturing stdout/stderr and the exit code.
// NotFound is set when the binary is not in PATH.
func (ExecRunner) Run(ctx context.Context, name string, args ...string) CommandResult {
	cmd := exec.CommandContext(ctx, name, args...)
	var out, errb bytes.Buffer
	cmd.Stdout, cmd.Stderr = &out, &errb
	err := cmd.Run()
	res := CommandResult{Stdout: out.String(), Stderr: errb.String()}
	if err == nil {
		return res
	}
	if errors.Is(err, exec.ErrNotFound) {
		res.NotFound = true
		res.Err = err
		return res
	}
	var ee *exec.ExitError
	if errors.As(err, &ee) {
		res.ExitCode = ee.ExitCode()
		return res
	}
	// Could not start (e.g. context cancelled). Report as error.
	res.ExitCode = -1
	res.Err = err
	return res
}

// runnerOf returns the configured runner or the production default.
func runnerOf(cfg Config) CommandRunner {
	if cfg.Runner != nil {
		return cfg.Runner
	}
	return ExecRunner{}
}

// serviceCheck reports a systemd unit as active. It judges on the "active"
// output rather than the exit code or localized text.
type serviceCheck struct {
	id, name, unit string
}

func (c serviceCheck) ID() string   { return c.id }
func (c serviceCheck) Name() string { return c.name }

func (c serviceCheck) Run(ctx context.Context, cfg Config) Result {
	ctx, cancel := context.WithTimeout(ctx, cfg.Timeouts.Command)
	defer cancel()
	res := runnerOf(cfg).Run(ctx, "systemctl", "is-active", c.unit)
	if res.NotFound {
		return Result{Status: StatusFail, Message: "systemctl not found"}
	}
	state := strings.TrimSpace(res.Stdout)
	if state == "active" {
		return Result{Status: StatusPass, Message: "active"}
	}
	if state == "" {
		state = "inactive"
	}
	return Result{Status: StatusFail, Message: state}
}

package health

import "context"

// configCheck validates a config file by invoking a validator binary. A
// missing binary is a WARN (tool not installed); a non-zero exit is a FAIL
// (config invalid).
type configCheck struct {
	id, name, bin string
	args          func(cfg Config) []string
}

func (c configCheck) ID() string   { return c.id }
func (c configCheck) Name() string { return c.name }

func (c configCheck) Run(ctx context.Context, cfg Config) Result {
	ctx, cancel := context.WithTimeout(ctx, cfg.Timeouts.Command)
	defer cancel()
	res := runnerOf(cfg).Run(ctx, c.bin, c.args(cfg)...)
	if res.NotFound {
		return Result{Status: StatusWarn, Message: c.bin + " not installed"}
	}
	if res.ExitCode == 0 && res.Err == nil {
		return Result{Status: StatusPass, Message: "valid"}
	}
	return Result{Status: StatusFail, Message: "invalid config"}
}

func singboxConfigCheck() Check {
	return configCheck{
		id: "config.singbox", name: "sing-box config", bin: "sing-box",
		args: func(cfg Config) []string { return []string{"check", "-c", cfg.SingboxConfig} },
	}
}

func caddyConfigCheck() Check {
	return configCheck{
		id: "config.caddy", name: "caddy config", bin: "caddy",
		args: func(cfg Config) []string {
			return []string{"validate", "--config", cfg.CaddyConfig, "--adapter", "caddyfile"}
		},
	}
}

import (
	"context"

	"os"
	"strconv"
	"strings"

// udpPortListening scans /proc/net/udp-style files for a local port. The
// local address column is "HEXIP:HEXPORT"; port 443 is 0x01BB.
func udpPortListening(paths []string, port int) (bool, error) {
	target := strings.ToUpper(fmt.Sprintf("%04X", port))
	var readAny bool
	for _, p := range paths {
		data, err := os.ReadFile(p)
		if err != nil {
			if os.IsNotExist(err) {
				continue
			}
			return false, err
		}
		readAny = true
		lines := strings.Split(string(data), "\n")
		for i, line := range lines {
			if i == 0 { // header
				continue
			}
			fields := strings.Fields(line)
			if len(fields) < 2 {
				continue
			}
			local := fields[1] // HEXIP:HEXPORT
			idx := strings.LastIndex(local, ":")
			if idx < 0 {
				continue
			}
			if strings.ToUpper(local[idx+1:]) == target {
				return true, nil
			}
		}
	}
	if !readAny {
		return false, os.ErrNotExist
	}
	return false, nil
}

// ValidToken reports whether s matches the subscription token format.
func ValidToken(s string) bool { return tokenPattern.MatchString(s) }

type tokenCheck struct{}

func (tokenCheck) ID() string   { return "subscription.token" }
func (tokenCheck) Name() string { return "subscription token" }

	if cfg.Token == "" {
		return Result{Status: StatusFail, Message: "token unavailable"}
	}

		return Result{Status: StatusFail, Message: "invalid token format"}
	}

}

type subFileCheck struct {
	id, name, filename string

func (c subFileCheck) ID() string   { return c.id }
func (c subFileCheck) Name() string { return c.name }

func (c subFileCheck) Run(ctx context.Context, cfg Config) Result {
	if cfg.Token == "" {
		return Result{Status: StatusFail, Message: "token unavailable"}
	}
	path := filepath.Join(cfg.SubscriptionRoot, cfg.Token, c.filename)
	info, err := os.Stat(path)
	if err != nil {
		return Result{Status: StatusFail, Message: "missing"}
	}
	if info.Size() == 0 {
		return Result{Status: StatusFail, Message: "empty"}
	}
	if _, err := os.ReadFile(path); err != nil {
		return Result{Status: StatusFail, Message: "unreadable"}
	}
	return Result{Status: StatusPass, Message: fmt.Sprintf("present, %s", humanSize(info.Size()))}
}

// humanSize renders a byte count compactly (e.g. "8.2 KB").
func humanSize(n int64) string {
	switch {
	case n >= 1<<20:
		return fmt.Sprintf("%.1f MB", float64(n)/(1<<20))
	case n >= 1<<10:
		return fmt.Sprintf("%.1f KB", float64(n)/(1<<10))
	default:
		return fmt.Sprintf("%d B", n)
	}
}

import (
	"context"
	"crypto/tls"
	"fmt"
	"net"
	"net/http"
	"time"

const certWarnWindow = 14 * 24 * time.Hour

func loopbackTLSAddr(cfg Config) string {
	if cfg.LoopbackTLSAddr != "" {
		return cfg.LoopbackTLSAddr
	}
	return "127.0.0.1:443"
}

// dialLoopbackTLS opens a verified TLS connection to the loopback address
// while presenting SNI = cfg.Domain and verifying the cert against cfg.Domain
// using cfg.RootCAs (nil = system roots).
func dialLoopbackTLS(ctx context.Context, cfg Config) (*tls.Conn, error) {
	d := &tls.Dialer{
		NetDialer: &net.Dialer{Timeout: cfg.Timeouts.TLS},
		Config:    &tls.Config{ServerName: cfg.Domain, RootCAs: cfg.RootCAs},
	}
	conn, err := d.DialContext(ctx, "tcp", loopbackTLSAddr(cfg))
	if err != nil {
		return nil, err
	}
	return conn.(*tls.Conn), nil
}

type httpSubCheck struct{}

func (httpSubCheck) ID() string   { return "http.subscription" }
func (httpSubCheck) Name() string { return "clash subscription" }

func (httpSubCheck) Run(ctx context.Context, cfg Config) Result {
	if cfg.Domain == "" {
		return Result{Status: StatusFail, Message: "no domain"}
	}
	if cfg.Token == "" {
		return Result{Status: StatusFail, Message: "token unavailable"}
	}
	ctx, cancel := context.WithTimeout(ctx, cfg.Timeouts.HTTP)
	defer cancel()
	addr := loopbackTLSAddr(cfg)
	transport := &http.Transport{
		DialContext: func(ctx context.Context, network, _ string) (net.Conn, error) {
			// Ignore the URL host; always dial the loopback address.
			return (&net.Dialer{Timeout: cfg.Timeouts.TCPConnect}).DialContext(ctx, network, addr)
		},
		TLSClientConfig: &tls.Config{ServerName: cfg.Domain, RootCAs: cfg.RootCAs},
	}
	client := &http.Client{Transport: transport}
	url := fmt.Sprintf("https://%s/%s/clash.yaml", cfg.Domain, cfg.Token)
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
	if err != nil {
		return Result{Status: StatusFail, Message: "bad request"}
	}
	resp, err := client.Do(req)
	if err != nil {
		return Result{Status: StatusFail, Message: "request failed"}

package health

import (
	"context"
	"syscall"

const minFreeBytes = 500 * 1024 * 1024 // 500 MB

// statfsFree returns free bytes available on the filesystem holding path.
func statfsFree(path string) (uint64, error) {
	var st syscall.Statfs_t
	if err := syscall.Statfs(path, &st); err != nil {
		return 0, err
	}
	return st.Bavail * uint64(st.Bsize), nil
}

type diskCheck struct{}

func (diskCheck) ID() string   { return "disk.space" }
func (diskCheck) Name() string { return "disk space" }

func (diskCheck) Run(ctx context.Context, cfg Config) Result {
	path := cfg.SubscriptionRoot
	if path == "" {
		path = "/"
	}
	free := cfg.DiskFree
	if free == nil {
		free = statfsFree
	}
	n, err := free(path)
	if err != nil {
		return Result{Status: StatusFail, Message: "statfs failed"}
	}
	if n < minFreeBytes {
		return Result{Status: StatusWarn, Message: humanSize(int64(n)) + " free"}
	}
	return Result{Status: StatusPass, Message: humanSize(int64(n)) + " free"}
}

package health

import (
	"encoding/json"
	"os"
	"strings"
)

// Defaults holds the production file locations. Tests override them.
type Defaults struct {
	SingboxConfig   string
	CaddyConfig     string
	SubscriptionRoot string
	TokenFile       string
	LegacyTokenFile string
	InstallJSON     string
}

// ProdDefaults returns the verified real paths.
func ProdDefaults() Defaults {
	return Defaults{
		SingboxConfig:    "/etc/sing-box/config.json",
		CaddyConfig:      "/etc/caddy/Caddyfile",
		SubscriptionRoot: "/var/www/proxy-sub",
		TokenFile:        "/var/lib/singbox-sub-manager/token",
		LegacyTokenFile:  "/etc/proxy-sub-token",
		InstallJSON:      "/etc/singbox-sub-manager/install.json",
	}
}

type installState struct {
	Domain           string `json:"domain"`
	SingboxConfig    string `json:"singbox_config"`
	CaddyConfig      string `json:"caddy_config"`
	SubscriptionRoot string `json:"subscription_root"`
	TokenFile        string `json:"token_file"`
}

func parseInstallJSON(path string) (installState, bool) {
	data, err := os.ReadFile(path)
	if err != nil {
		return installState{}, false
	}
	var s installState
	if err := json.Unmarshal(data, &s); err != nil {
		return installState{}, false
	}
	return s, true
}

// parseCaddyfileDomain returns the first site-block address that looks like a
// domain (contains a dot, no scheme, no path). Caddy site blocks open with
// "example.com {".
func parseCaddyfileDomain(path string) (string, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return "", err
	}
	for _, line := range strings.Split(string(data), "\n") {
		line = strings.TrimSpace(line)
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		if !strings.HasSuffix(line, "{") {
			continue
		}
		addr := strings.TrimSpace(strings.TrimSuffix(line, "{"))
		if strings.Contains(addr, "://") || strings.Contains(addr, "/") || strings.ContainsAny(addr, " \t") {
			continue
		}
		if strings.Contains(addr, ".") {
			return addr, nil
		}
	}
	return "", nil
}

func firstNonEmpty(vals ...string) string {
	for _, v := range vals {
		if v != "" {
			return v
		}
	}
	return ""
}

// readToken reads and validates the subscription token, trying the primary
// then the legacy path. Returns "" and an error message when unavailable.
func readToken(primary, legacy string) (string, error) {
	for _, p := range []string{primary, legacy} {
		if p == "" {
			continue
		}
		data, err := os.ReadFile(p)
		if err != nil {
			continue
		}
		tok := strings.TrimSpace(string(data))
		if ValidToken(tok) {
			return tok, nil
		}
	}
	return "", os.ErrNotExist
}

// ResolveConfig assembles a production Config from flag, install.json, and
// Caddyfile, in that precedence for the domain.
func ResolveConfig(domainFlag string, d Defaults) Config {
	state, _ := parseInstallJSON(d.InstallJSON)

	singbox := firstNonEmpty(state.SingboxConfig, d.SingboxConfig)
	caddy := firstNonEmpty(state.CaddyConfig, d.CaddyConfig)
	subRoot := firstNonEmpty(state.SubscriptionRoot, d.SubscriptionRoot)
	tokenFile := firstNonEmpty(state.TokenFile, d.TokenFile)

	domain := domainFlag
	if domain == "" {
		domain = state.Domain
	}
	if domain == "" {
		domain, _ = parseCaddyfileDomain(caddy)
	}

	cfg := Config{
		Domain:           domain,
		SingboxConfig:    singbox,
		CaddyConfig:      caddy,
		SubscriptionRoot: subRoot,
		TokenFile:        tokenFile,
		Timeouts:         DefaultTimeouts(),
	}
	cfg.Token, cfg.TokenErr = readToken(tokenFile, d.LegacyTokenFile)
	return cfg
}
```

package health

import (
	"encoding/json"
	"fmt"
	"io"
	"strings"
	"text/tabwriter"
	"time"
)

// Report is the full health run, JSON-serializable with a stable schema.
type Report struct {
	Status     Overall  `json:"status"`
	Timestamp  string   `json:"timestamp"`
	DurationMS int64    `json:"duration_ms"`
	Checks     []Result `json:"checks"`
	Summary    Summary  `json:"summary"`
}

// BuildReport assembles a Report from results and the run start time.
func BuildReport(results []Result, started time.Time) Report {
	return Report{
		Status:     Aggregate(results),
		Timestamp:  time.Now().Format(time.RFC3339),
		DurationMS: time.Since(started).Milliseconds(),
		Checks:     results,
		Summary:    Summarize(results),
	}
}

func label(s Status) string {
	switch s {
	case StatusPass:
		return "PASS"
	case StatusWarn:
		return "WARN"
	default:
		return "FAIL"
	}
}

// RenderText writes the human-readable table.
func RenderText(w io.Writer, rep Report) {
	fmt.Fprintln(w, "singbox-sub-manager health")
	tw := tabwriter.NewWriter(w, 0, 2, 2, ' ', 0)
	for _, c := range rep.Checks {
		fmt.Fprintf(tw, "%s\t%s\t%s\n", label(c.Status), c.Name, c.Message)
	}
	tw.Flush()
	fmt.Fprintf(w, "Overall: %s\n", strings.ToUpper(string(rep.Status)))
	fmt.Fprintf(w, "%d passed, %d warning, %d failed\n", rep.Summary.Passed, rep.Summary.Warnings, rep.Summary.Failed)
}

// RenderJSON writes the stable JSON document.
func RenderJSON(w io.Writer, rep Report) error {
	enc := json.NewEncoder(w)
	enc.SetIndent("", "  ")
	return enc.Encode(rep)
}
```
